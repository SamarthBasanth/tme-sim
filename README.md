# tmesim

**A Stage 0 kill-test for patient-specific glioblastoma drug-response prediction.**

`tmesim` reconstructs a patient-specific tumor microenvironment (TME) from a
sample, simulates drug transport and cell kill through it with mechanistic
physics, and then asks one blunt question:

> **Does a mechanistic microenvironment + drug-transport model predict observed
> drug response *better than a cheap, non-spatial baseline*?**

If it does not beat the baseline, the approach is not ready and we should say so.
The validation harness is deliberately adversarial rather than flattering. This
repository is the machinery that lets us run that test honestly.

---

## What this is (and is not)

**It is:** an end-to-end, runnable scaffold that takes a digital microenvironment
all the way to a scored prediction — reconstruction → continuum physics (drug
diffusion, oxygen, interstitial pressure) → agent-based pharmacodynamic kill →
cohort-level validation against baselines. It runs today on **synthetic patients
with known ground truth** and on **best-effort open data** where such data can be
acquired.

**It is not:** a clinically validated tool. The parameters are order-of-magnitude
biologically plausible, not patient-calibrated. The physics is 2D. On synthetic
cohorts the "ground truth" is generated by the same broad biological assumptions
the model encodes, so a synthetic pass demonstrates that the *machinery is
correct and the signal is recoverable* — it does **not** demonstrate real-world
predictive power. Establishing that requires controlled-access, paired
sample→outcome data (see *What would make this real*).

We keep this boundary explicit on purpose. A Stage 0 kill-test earns the right to
raise money and pursue real data only if it is honest about what it has and has
not shown.

---

## Why glioblastoma

Glioblastoma (GBM) is the case where the microenvironment is not a second-order
correction — it is the crux of the problem:

- **Drug delivery is the binding constraint.** The blood-brain barrier (BBB)
  admits only a small fraction of most systemic agents into tissue, and that
  fraction is spatially heterogeneous.
- **Diffusion and infiltration dominate.** GBM has no clean margin; malignant
  cells infiltrate normal brain well beyond any resectable or contrast-enhancing
  boundary, and the drug has to physically reach them.
- **Transport-limited regions are exactly the resistant ones.** Sparse, tortuous
  vasculature in the tumor core drives hypoxia (a resistance state) *and* poor
  delivery in the same place. Elevated interstitial fluid pressure (the Jain
  effect) further opposes inward drug flux.

So GBM is the disease where a *spatial, transport-aware* model has the best a
priori chance of beating a non-spatial one. If mechanistic microenvironment
modeling cannot add value here, it is unlikely to add value elsewhere. That makes
GBM the right first kill-test.

## The scientific claim under test

The Stage 0 experiment (`tmesim.validation.experiment.run_stage0_experiment`)
scores the simulator's `predicted_response` against three cheap baselines on a
cohort:

| Baseline | What it uses | What it ignores |
|---|---|---|
| `baseline_mean` | a constant prior (cohort mean response) | everything patient-specific |
| `baseline_intrinsic_sensitivity` | mean per-cell intrinsic drug sensitivity only | all spatial transport |
| `baseline_expression_logreg` | logistic regression on non-spatial feature scalars | tissue geometry, delivery, hypoxia |

The mechanistic model **passes only if it exceeds the *best* baseline** on the
primary metric (`roc_auc`) by a margin. The verdict and `beat_baseline` flag are
written honestly into `ExperimentResult`; a null or negative result is a valid,
reportable outcome of the test.

The scientific point of the intrinsic-sensitivity baseline is subtle and
important: it isolates the *marginal value of the spatial transport physics*. If
the full simulation cannot beat a model that knows each cell's intrinsic
sensitivity but nothing about delivery, then the transport machinery is not
earning its complexity.

## Install

Requires Python ≥ 3.9. No network is needed except for the optional real-data
acquisition step.

```bash
git clone <this-repo> tme-sim
cd tme-sim
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -e .
```

This pulls in numpy, scipy, matplotlib, pandas, scikit-image, networkx,
scikit-learn, requests, and tifffile (see `pyproject.toml`).

## Quickstart

```bash
# One synthetic patient: reconstruct, simulate, and write plots.
python -m tmesim.cli demo

# Full Stage 0 cohort experiment (synthetic by default), with baselines + verdict.
python -m tmesim.cli run --n 40 --data synthetic

# Try to pull open GBM data first, fall back to synthetic if none is usable.
python -m tmesim.cli run --n 40 --data auto

# Best-effort live download of open datasets into ./data_cache/.
python -m tmesim.cli acquire
```

`demo` produces microenvironment and simulation figures. `run` produces the
validation figures, a JSON results file, and an honest `results/report.md`
embedding the figures and the pass/fail verdict.

Run programmatically:

```python
from tmesim.core import SimConfig
from tmesim.data.synthetic import generate_synthetic_cohort
from tmesim.validation.experiment import run_stage0_experiment

records = generate_synthetic_cohort(n=40, seed=0)
exp = run_stage0_experiment(records, SimConfig(seed=0), out_dir="results")
print(exp.verdict, exp.beat_baseline)
```

## Module map

The frozen public interface for every module is
[`ARCHITECTURE_CONTRACT.md`](ARCHITECTURE_CONTRACT.md). The data-flow and physics
detail is in [`docs/architecture.md`](docs/architecture.md).

```
data/  ──►  reconstruct/  ──►  Microenvironment  ──►  physics/ + cells/  ──►  sim/  ──►  validation/  ──►  viz/
(sample)     (build TME)        (core object)          (transport+kill)      (engine)   (beat baseline?)      (report)
```

| Package | Responsibility |
|---|---|
| `tmesim.core` | **Frozen** data model: `Domain`, `Microenvironment`, `CellPopulation`, `TissueFields`, config dataclasses, `DRUG_LIBRARY`, and the `*Result` containers. Everything else builds against these. Do not modify. |
| `tmesim.data` | `synthetic.py` — generate biologically-plausible GBM patients with *known* ground truth. `acquire.py` / `loaders.py` — best-effort download and parse of open GBM data (Ivy GAP, TCGA-GBM, DepMap/GDSC). |
| `tmesim.reconstruct` | Sample → digital TME. `segmentation.py` (nuclei → phenotyped cells), `spatial.py` (cells → ECM/vascular fields), `vasculature.py` (tortuous vessel network, sparse in core), `assemble.py` (bundle into a `Microenvironment`). |
| `tmesim.physics` | Continuum fields. `diffusion.py` (convection-diffusion-reaction drug transport → `TransportResult`), `oxygen.py` (steady-state O₂ + hypoxia labeling), `pressure.py` (interstitial fluid pressure + convective velocity, the Jain effect). |
| `tmesim.cells` | Agent-based cell response. `agents.py` (relabel viable/hypoxic/quiescent from oxygen), `pkpd.py` (map local drug AUC → per-cell kill probability via a Hill model, modulated by sensitivity/hypoxia). |
| `tmesim.treatment` | `drugs.py` — drug lookup, plasma PK profile, and the spatial delivery source (vasculature × BBB penetrance). |
| `tmesim.sim` | `engine.py` — `simulate_response`, the deterministic integrator that runs the full per-patient pipeline and emits a `SimulationResult`. |
| `tmesim.validation` | `baselines.py` (the cheap models to beat), `metrics.py` (ROC-AUC, Brier, calibration, Spearman), `experiment.py` (the Stage 0 harness + verdict). |
| `tmesim.viz` | `plots.py` (microenvironment / simulation / validation figures) and `report.py` (assemble `results/report.md`). |
| `tmesim.cli` | argparse entry point: `demo`, `run`, `acquire`. |

## What would make this real

Stage 0 proves the machinery. It does not prove clinical predictive power. The
path from here is a staged de-risking, and each stage is a go/no-go gate:

- **Stage 1 — Calibration.** Replace order-of-magnitude parameters (diffusivity,
  BBB penetrance, IC50s, oxygen/consumption rates) with values fit to measured
  data. Sensitivity analysis to find which parameters the verdict actually
  depends on.
- **Stage 2 — Real reconstruction.** Drive the pipeline from real spatial data
  (e.g. spatial transcriptomics / multiplex imaging of GBM) instead of synthetic
  tissue, and validate the reconstruction itself against held-out measurements.
- **Stage 3 — Retrospective validation.** Run the Stage 0 kill-test on
  *controlled-access, paired sample→outcome cohorts* — the same adversarial
  baseline comparison, but with real biology and real outcomes. This is the first
  point at which a "beat the baseline" result means something clinically.
- **Stage 4 — 3D and mechanism depth.** Lift the physics to 3D where geometry
  demands it; add mechanisms (immune, resistance dynamics) only if Stage 3 shows
  they are needed to explain the residual.
- **Stage 5 — Prospective validation.** Predict response *before* outcomes are
  known, on a pre-registered cohort. Nothing short of this is evidence of a
  clinically useful model.

The honest one-line summary: **today this is a correct and adversarially-tested
simulation engine with a null-result-friendly harness; real validation needs
controlled-access paired data we do not yet have.**

See [`docs/data_acquisition_plan.md`](docs/data_acquisition_plan.md) for the
specific controlled-access datasets (HTAN, spatial Visium/Xenium GBM on GEO, PDO
drug screens) a funded team would use for Stages 2–3.
