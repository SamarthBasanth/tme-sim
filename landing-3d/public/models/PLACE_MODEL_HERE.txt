Drop a real, scan-derived tumor model here as:

    public/models/tumor.glb

TumorModel.tsx checks for this file at runtime (a HEAD request) and will
switch from the procedural placeholder to loading this file automatically —
no code changes required. See components/canvas/GLTFTumor.tsx for the
optional "core" / "edema" / "margin" (or "tissue") named-node convention
that re-enables the Segmentation scene's split animation for a real model.

Keep the file reasonably small/compressed (glTF-Binary, Draco or Meshopt
compression recommended) since it is fetched on page load.
