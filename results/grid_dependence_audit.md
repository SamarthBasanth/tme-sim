# Grid-dependence audit — which published claims depend on `dx`, and which would move

**Read-only audit. No existing file was edited, no PDE was re-solved, no number was
recomputed that the repo already records.** Every figure below is either quoted from an
existing `results/*.md`, read out of an existing JSON/JSONL, read out of source, or is
elementary arithmetic on quoted figures (band-edge distances, marked as such). Where a
number genuinely is not recorded anywhere, this file says **"not recorded"** rather than
computing it — the absence is part of the finding.

Commissioned because docetaxel's breast 3-D:2-D verdict is now known to flip between
`dx = 12 um` and `dx = 24 um` (`results/dtissue_sensitivity.md` §7.2/§7.3), and it is the
breast panel's only FAIL — the result cited throughout the repo as evidence the
calibration is falsifiable rather than tuned. Nobody had ever enumerated what else moves
with the mesh.

---

## 0. The headline finding, stated first because it changes how to read everything else

**The 3-D:2-D ratio has no grid-error cancellation structure at all.** The audit was
commissioned on the hypothesis that ratios taken between two runs on the same tissue at
the same `dx` should be robust because a common-mode discretisation error largely
cancels. For this family of verdicts — the breast panel, the GBM panel, the docetaxel
FAIL, the thing the convergence studies are being run to check — **that hypothesis is
false, and it is false structurally, not marginally.**

`tmesim/validation/kill_calibration.py::decompose`, lines 500-519:

    ref_unit = float(np.percentile(e_unit, reference_pct))   # p99 of the GRID field
    plasma   = float(c_bath) / ref_unit
    E        = plasma * e_unit                                # GRID field
    p3       = p_hill(E, ic50, hill, max_kill)                # GRID
    p2       = float(p_hill(c_bath, ic50, hill, max_kill))    # SCALAR — no grid
    kill_3d  = float(np.mean(p3 * sens * resist))             # GRID
    kill_2d  = float(p2 * np.mean(sens))                      # SCALAR × scalar
    ratio_exact = float(kill_3d / kill_2d)

The denominator is a closed-form Hill evaluation at the bath concentration. It contains
no field, no mesh, no solve. At the 1×IC50 reporting convention it is exactly `0.5` — and
that is confirmed empirically in `results/sweep/gridconv_records.jsonl`, where every
record carries `"kill_2d_model": 0.5` regardless of `dx_um`.

So the "3-D:2-D ratio" is **not a ratio of two runs**. It is a grid-dependent numerator
divided by a grid-free constant. There is nothing for a common-mode grid error to cancel
against. The cancellation genuinely measured elsewhere in the repo — 84-86% for the
delivery-law change (`results/breast_kill_revalidation.md` §5), and the algebraically
*exact* cancellation for a uniform rescaling of the exposure field
(`results/dtissue_sensitivity.md` §5) — is cancellation of a **multiplicative scale**
error, which the `plasma = c_bath / ref_unit` renormalisation divides out by
construction. A mesh change is not a scale error. It is a **shape** change to the
exposure distribution, and `results/dtissue_sensitivity.md` §5 says so in its own words:

> "The ratio can therefore only respond to a change in the SHAPE of the exposure
> distribution, never to its scale."

A grid refinement is precisely and only a change of shape. **The verdict class the repo
treats as its most robust output is the one with the least protection against the
perturbation now under test.**

This is corroborated by measurement, not just by reading the code. The same file's
`frozen`-mode cancellation table (§5, lines 321-325) reports `surviving vs exposure` of
**7.25 to 21.34** — values far above 1.0, which that document itself defines as
"**above 1.0 = the score is MORE sensitive than the absolute output, i.e.
anti-cancellation**". For six of the six scored breast drugs, in that mode, the scored
ratio moves 7-21× further in log space than the absolute exposure it is built from.

## 2. Risk classification, and where the evidence contradicts the hypotheses

### 2.1 Hypothesis 1 — "ratios between two runs on the same tissue at the same `dx` are robust": **REFUTED for the verdict class it was meant to protect.**

Reason, in full, in §0. Summarised:

* The 3-D:2-D ratio's denominator `kill_2d = p_hill(c_bath, …) × mean(sens)` is a scalar
  with no mesh in it (`kill_calibration.py:514`), verified as exactly `0.5` in every
  record of `results/sweep/gridconv_records.jsonl`. There are not two runs. There is one
  run over a constant.
* The cancellation the repo has actually measured is of **multiplicative scale** error
  (84-86%, `breast_kill_revalidation.md` §5; algebraically exact,
  `dtissue_sensitivity.md` §5), which the `plasma = c_bath / p99(e_unit)` renormalisation
  removes by construction. Grid error is a **shape** perturbation, which the same section
  states the ratio *can* and *only* responds to.
* Measured anti-cancellation, `dtissue_sensitivity.md` §5 `frozen` mode: `surviving vs
  exposure` = **7.25-21.34** for all six scored breast drugs, against that document's own
  threshold of 1.0 for "no cancellation".
* Measured directly against `dx`: the breast ratios move **1.2% to 19.1%** for a single
  2× coarsening (`dtissue_sensitivity.md` §7.2, derived below in §3.2). That is not the
  behaviour of a robust statistic.

**The hypothesis survives in a narrower form that should be quoted instead:** ratios are
robust to errors that scale the exposure field *uniformly*. Diffusivity is close to such
an error (hence the 99%-plus cancellation in `recal` mode: `surviving vs exposure`
0.014-0.022, i.e. **97.8-98.6% cancelled**, `dtissue_sensitivity.md` §5 lines 332-336 —
note the frequently-quoted "99.6%" figure does **not** appear in that file as a printed
number). The delivery law was close to such an error (84-86%). **The mesh is not.**

### 2.2 Hypothesis 2 — "absolute levels and lengths are far more exposed": **CONFIRMED, and already demonstrated to flip a verdict.**

* `results/vessel_profile.md` §"Scorecard" (lines 384-387) publishes doxorubicin's real-
  tissue empirical half-distance as **41.5 µm at `dx = 12`** → *PASS (inside the measured
  40-50 um band)*, and **13.0 µm at `dx = 30`** → ***FAIL (more than 3x off the measured
  band)***. **Same drug, same tissue, same physics, same delivery law, both arms — the
  verdict is decided by the mesh.** This is a completed, published, dx-driven verdict flip
  that predates the docetaxel one and has never been listed as such.
* The same document's fitted `L` and empirical `d½` differ substantially between arms
  (§"Register", lines 462-467): temozolomide `L` = 277.4 µm (`dx = 12` repaired), 280.0
  (`dx = 12` native), **181.0** (`dx = 30`), and under exchange-ON 396.3 / 389.8 /
  **403.1**. That document itself flags the `dx = 30` fit as the weakest in the report
  (R² 0.856/0.827 against ≥0.976 on the 12 µm arms).
* The same document also records a *qualitative* mesh failure that no ratio can survive:
  *"At dx = 12 µm the cell-derived tissue mask is 26,058 disconnected fragments (largest =
  0.7% of tissue), so lateral diffusion is switched off"* and — its own words —
  ***"Any perivascular-gradient number quoted from a native dx ≤ 20 µm run is a
  source-geometry measurement, not a transport measurement."*** The primary arm works
  around this with a morphological repair whose closing radius is *"a free parameter"* and
  *"not measured"*. **`dx` and the mask repair are confounded in every vessel_profile
  number**, which is why §1.2 marks its convergence check "partial".
* `results/delivery_metrics.md` quantifies level drift on its own 20/15/12 ladder:
  `median_tumor_auc` *"not itself grid-converged on this ladder (1.5% worst-drug drift)"*,
  `penetration_index` moves 3.5% relative over the refinement step *"while its entire
  spread across the 5-drug panel at dx = 12 µm is only 53.0%"*.

### 2.3 Hypothesis 3 — "anything at a threshold or band edge is exposed regardless of type": **CONFIRMED, and it is the dominant risk.** But with one large and load-bearing exception.

Confirmed by the two known flips (docetaxel, doxorubicin `d½`) and by the ranking in §3.

**The exception, which is good news and should be stated plainly: the project's most-cited
external validation is completely grid-free.** The out-of-sample PK anchors —
mitoxantrone **48.2 µm** and topotecan **83.6 µm** against a 36.1-108.2 µm e-fold band,
published in `results/vessel_promotion.md` §4.1, `results/calibration.md`,
`results/pk_multidrug.md` and `results/REAL_VALIDATION.md` — come from
`pk_reality.penetration_length_um`, a closed-form `L = √(D_eff / k)` with no mesh, no
domain and no solve (`validation/calibration.py:239-241, 342-373`). `vessel_promotion.md`
says as much in its own terms: *"identical to the last digit under both source fields.
The deciding test does not degrade, because it cannot."* The same is true of
`alpha = 148.608…` itself, of `results/glioma_regional_pk.md` (a structure →
`bbb_penetrance` partition calculation with no `Domain` and no PDE anywhere in
`validation/glioma_regional_pk.py`), of `results/breast_transport_anchors.md`, and of the
whole `molecular/` chain.

**Consequence for the blast radius: no convergence result can invalidate the calibration
constant or the out-of-sample PK verdicts.** Whatever the ladders return, `alpha` stands
and 2/2 out-of-sample stands. The exposure is confined to what the *engine* computes on
top of them.

### 2.4 A fourth class the hypotheses did not name: **verdicts whose band is itself a mesh-dependent object.**

`results/vessel_profile.md`'s verdict tiers (`vessel_profile.py:865-887`) compare a
half-distance to a **fixed literature band** (40-50 µm, mid 45 µm). The predicted
half-distance is read off a profile binned in **10 µm distance bins**
(`vessel_profile.py:143`, commented *"comfortably above dx = 12 um"*). At `dx = 30 µm` the
bin width is *below* the mesh spacing, so the `dx = 30` arm's `d½ = 13.0 µm` is being read
at a resolution the grid cannot supply. That is an additional, separate mechanism by which
that arm's FAIL is a numerical artefact rather than a physics result — and it means the
`dx = 30` row is not a valid convergence control for `dx = 12` even though the document
presents it as *"an independent cross-check"*.

## 3. The ranked near-boundary table — which verdicts are likely to move

### 3.1 Method

For every scored verdict in `results/` with a numeric prediction and a numeric band, the
distance from the prediction to its **nearest band edge** is expressed as a percentage of
that edge. Band edges in ratio space were converted from the published fold bands with the
report's own Hill inversion, `r = 2 / (1 + f^1.2)`
(`breast_kill_revalidation.md` §2) — this reproduces every published ratio band exactly
(docetaxel 0.0152-0.1463, cisplatin 0.2086-1.5004, doxorubicin 0.0575-1.0000), which is
the check that the conversion is the right one. **Temozolomide/GBM is excluded from that
conversion** because it is reported at 100 µM rather than 1×IC50; its published band
(0.1590-0.4622, `kill_calibration.md` §3) is used directly. Half-distance verdicts use
the tier logic in `vessel_profile.py:865-887` (`ratio_to_mid` against mid = 45 µm, PASS
inside 40-50, PASS(wide) inside 25-75, PASS(3×) within 3× of mid, else FAIL).

This is arithmetic on published numbers. **No PDE was re-solved.**

### 3.2 Measured grid sensitivity, for calibration of the ranking

The only place a scored verdict's response to `dx` alone has ever been measured is
`results/dtissue_sensitivity.md` §7.2 (`dx = 12` → `dx = 24`, everything else fixed).
Converting its published deltas to relative moves:

| drug (breast) | ratio at `dx = 12` | ratio at `dx = 24` | Δ | **relative move for one 2× coarsening** |
|---|---:|---:|---:|---:|

`vessel_profile.md`; one is docetaxel. **Every one of the five is a LENGTH or a
half-distance except docetaxel**, which is the threshold case. Both hypotheses 2 and 3 are
vindicated by the ranking; hypothesis 1 is not, because the ratio class turns out to have
no protection and simply happens to sit on wide literature bands.

**The single most useful prediction this audit can make in advance of the ladders
landing:**

* **Docetaxel will move, and it may pass.** It fails by 1.5% and its measured response to
  a 2× mesh change is 19.1% in the direction of the band. The direction under
  *refinement* (12 → 8 or 6) is **not recorded anywhere** — only coarsening has been
  measured. If refinement continues the monotone trend of coarsening, docetaxel moves
  further out and the FAIL hardens; if it reverses, the panel's only FAIL disappears and
  with it the repo's principal evidence that the calibration is falsifiable rather than
  tuned. **The breast ladder must report the sign, not just the magnitude.**
* **Paclitaxel is the second drug to watch** (18.6% response), but it needs ~5× the
  measured move and is unlikely to cross.
* **Nothing else in the breast panel should move.** Ranks 9-12 have safety factors of
  16-43.
* **The GBM panel is the unquantified risk.** Cisplatin/GBM sits 33.8% from its edge and
  has *never* been run at a second resolution. If the GBM ratios turn out to be as
  grid-sensitive as docetaxel (19% per 2×), cisplatin/GBM is ~1.8 doublings from its edge
  — safe against a 2× change, not safe against a 4× one. The GBM ladder should report the
  per-drug ratio at every rung, not just `kill_fraction`.

## 5. Verdict — how exposed is this project

**50 of 83 published result documents (60%), and 85% of the documents that report any
number this codebase computed, depend on a chosen mesh.** Eight of those 50 do not state
what mesh they used, and two of the eight ran at `dx = 11 µm`, a value that exists nowhere
else in the project and on no convergence ladder ever run.

**Most of this project's absolute numbers are grid-exposed and, in eight documents,
grid-exposed and undocumented.** That is the plain statement the brief asked for, and it
is accurate.

Eight documents contain some grid check. **None of them is of the breast section.** The
breast panel — the flagship, the ten-drug table, the docetaxel FAIL — is asserted to be
"grid-converged at `dx = 12 um`" on the authority of a ladder run on a GBM section. The
repo noticed and closed exactly this gap for Visium and never asked the question for
breast.

The evidence that the mesh is not the bottleneck is weaker than the repo believes. The one
elasticity table ever measured (`numerical_rigor.md` §4) puts `grid_dx_um` **first** among
four knobs for the penetration index, at 3.1× the knob its own prose credits; the prose
and the "Honest numerical verdict" both misread it. The same document's prose also reports
the wrong sign for the penetration index's grid trend relative to its own table, and it
disagrees with `cross_tissue.md` on that sign. **The three sentences most often quoted as
"the grid is fine" are all in `numerical_rigor.md`, and all three are contradicted by the
tables directly above them.**

Against that, three things genuinely reduce the blast radius and should not be
overstated away:

1. **The calibration constant and the out-of-sample PK verdicts are analytic and cannot
   move.** `alpha = 148.6`, mitoxantrone 48.2 µm, topotecan 83.6 µm, the whole `molecular/`
   chain, `glioma_regional_pk.md` — no mesh, no exposure. The deciding external test of
   this project survives any convergence result.
2. **No frozen numeric constant in `tmesim/core/config.py` and no hardcoded reference
   number in `tests/` was produced at a particular `dx`.** A mesh change is a
   `results/` regeneration, not a re-calibration and not a test rewrite. One prose claim in
   `PDEConfig.transvascular_exchange`'s docstring asserts `dx = 12 µm` is adequate and
   would need re-checking.
3. **Nine of the thirteen scored ratio verdicts sit 43-90% from their nearest band edge**,
   with measured grid sensitivities of 1-19% per 2× mesh change. They will move and they
   will not cross.

The exposure is therefore **concentrated, not diffuse**. Five verdicts sit within 10% of an
edge. Two of those five are *already known* to be decided by the mesh — docetaxel's breast
FAIL (`dtissue_sensitivity.md` §7.2) and doxorubicin's real-tissue half-distance, which is
a published **PASS at `dx = 12` and a published FAIL at `dx = 30` in the same table**
(`vessel_profile.md` §"Scorecard"). The remaining three are all in `vessel_profile.md` and
sit 0.6%, 0.7% and 7.3-13.8% from their edges.

**The specific risk to the project's narrative is narrow and should be named.** Docetaxel's
FAIL is the breast panel's only FAIL and is cited as proof the calibration is falsifiable.
It fails by **1.5%**. Its measured response to a single 2× mesh change is **19.1%** — 13×
its own margin — and the direction under *refinement* has never been measured. If the
breast ladder moves it inside, the panel becomes 6/6 PASS and the falsifiability claim
loses its only instance. That would not make the model wrong; it would make the strongest
available evidence that the model *can* be wrong evaporate on a numerical detail. **That
outcome should be planned for now, not argued about after the ladder lands.**
