GM \|fold error\| **1.9946x**, 6/6 within 10x, 4/6 within 3x, worst 6.944x.
Regional: levetiracetam model **1.1906x** vs measured **1.4522x**; cefazolin
model **5.8734x** vs measured **4.2635x**; anchor GM \|ratio error\|
**1.2963x**. Leak constant `L = 0.238`, unchanged.

**Why it did not move.** This is structural, not luck. The module imports
`molecular.descriptors`, `molecular.library`, `molecular.permeability` and
`reconstruct.barrier` — and nothing else from the model. None of those four
files appears in the diff of `4ad221f`, `01e6eb3`, `ceb96c0` or `0eca2fc`. The
validation never builds a reconstruction, never touches the vascular field, and
never runs the engine time loop, so it is *blind by construction* to all four
changes. The mapping it scores is assumption A1, `R_predicted = bbb_penetrance`,
a pure function of the drug's 2D descriptors.

That immunity is worth reading in both directions. It is why the claim survived
— and it is also the same fact the report already states as the validation's
central weakness: the model has no region term, so its pre-fix regional
prediction was exactly 1.00x. Nothing in this re-run changes that assessment.

## 4. (d) `reconstruction_fidelity` — the one that broke

### 4a. What moved

The region-marker half of the module is fine. PECAM1-in-perivascular
(d = 1.2926), VEGFA-in-necrotic (d = 1.3527) and CA9-in-necrotic (d = 0.6736)
all reproduce exactly, all at permutation p = 9.999e-05 over 10,000
permutations, on the same 3,468-spot Visium sample with the same region
distribution (core 786 / margin 90 / necrotic 1628 / perivascular 964). Region
labelling runs off `reconstruct.region_label` on Visium expression and is
independent of all four changes.

The cross-platform composition check is what broke. Both runs use the same
40,887 Xenium cells and the same 3,468 Visium spots; only the Xenium classifier
changed.

| cell type | Xenium **before** | Xenium **after** | Visium (unchanged) |
|---|---|---|---|
| TUMOR | 73.80% | **58.24%** | 82.66% |
| STROMAL | 7.92% | **11.78%** | 1.04% |
| IMMUNE | 8.54% | **19.48%** | 6.53% |
| ENDOTHELIAL | 9.74% | **10.50%** | 9.77% |

The endothelial column moved least — 9.74 → 10.50, exactly the number
`results/classifier_fix.md` predicts. But the *other three* moved a great deal,
and the concordance metrics are dominated by them:

* **Pearson r on the 4-vector: 0.997 → 0.980.** Still high, but the published
  number is stale.
* **Pearson r on the non-tumour subvector: 0.945 → 0.016.** This is the check
  the original report itself labelled "the harder test". It has collapsed to
  noise.
* **Composition ordering, rank ρ: 1.00 → 0.40.** Before, both platforms ranked
  the four classes identically (TUMOR > ENDOTHELIAL > IMMUNE > STROMAL). Now
  Xenium reads TUMOR > IMMUNE > STROMAL > ENDOTHELIAL while Visium still reads
  TUMOR > ENDOTHELIAL > IMMUNE > STROMAL. Three of four classes disagree.
* **Mean absolute difference: 4.44% → 12.21%**, 2.75x worse.

The report's verdict sentence — *"the reconstruction is cross-platform
self-consistent: two independent real assays + estimators agree on the
composition ordering (tumour-dominant, minority immune/endothelial/stromal) and
rough magnitudes"* — is no longer supported. Tumour-dominance survives. The
ordering of the three minority classes does not, and the magnitudes are off by
10–25 percentage points on TUMOR and IMMUNE.

### 4b. Attribution — proven, not inferred

Re-running `check_cross_platform_composition` with **only** the classifier
aggregation reverted to the legacy `mean_z` rule (everything else — vessel
geometry, discrete vascular field, engine — left at current defaults) reproduces
the original numbers exactly:

| metric | current default (`matched_null_z`) | legacy rule (`mean_z`) reverted | published before |
|---|---|---|---|
| Xenium TUMOR / STROMAL / IMMUNE / ENDO | 58.24 / 11.78 / 19.48 / 10.50 | 73.80 / 7.92 / 8.54 / 9.74 | 73.80 / 7.92 / 8.54 / 9.74 |
| Pearson r, 4-vector | 0.9803 | **0.9974** | 0.997 |
| Pearson r, non-tumour | 0.0159 | **0.9450** | 0.945 |
| mean abs. difference | 12.21% | **4.44%** | 4.44% |

So the attribution is exact and exclusive:

* **Change 1 (classifier arity fix) accounts for 100% of the move.**
* **Changes 2, 3 and 4 contribute exactly nothing** to this validation. Vessel
  geometry and the discrete vascular field alter `fields.vascular_density`, not
  cell-type calls; time-resolved PK is default-off and this check never runs the
  engine. Reverting the classifier alone recovers the published numbers to four
  decimal places, which it could not do if any other change were contributing.

### 4c. What this does and does not mean

It would be wrong to read this as "the model got worse". `results/classifier_fix.md`
establishes that `mean_z` carried a real arity bug — a class defined by one
marker scored systematically higher than a class defined by four — and that
`matched_null_z` removes it, cutting the endothelial spread across three real
sections from 2.91x to 1.49x. The corrected classifier is the better estimator.

What broke is the *claim*, and the honest reading is the same one
`classifier_fix.md` §6 already applied to the volume-EM anchor: **the 0.997 was
agreement between a biased estimator and another estimator, and its tightness
was coincidental.** Removing the bias from one side of a two-sided concordance
test necessarily breaks the concordance unless both sides shared the bias — and
here they plainly did not, because Visium NNLS deconvolution against the
Darmanis atlas has its own, different tumour-inflating tendency (82.66% TUMOR,
1.04% STROMAL) which the old Xenium rule happened to lean toward.

The correct conclusion is therefore not "concordance restored by reverting", but
**"cross-platform composition concordance is now an OPEN question, and the 0.997
figure must be retired from any external material."** It cannot be settled by
choosing whichever classifier makes the number look better — that is selecting
on the outcome. It needs an independent composition ground truth, which this
section does not have.

Two consequences that should be recorded rather than absorbed:

1. Anything downstream quoting "Pearson 0.997 cross-platform concordance" is now
   quoting a number that the current code does not produce.
2. The non-tumour Pearson of 0.016 is not merely "lower" — it is indistinguishable
   from no relationship over 3 points. Reporting it as a weakened pass would be
   dishonest; it is a fail.

## 5. (e) `pharmacology_real` — still structurally immune, verified

The prior run's claim that this module is structurally immune to the model
changes **still holds, and was verified rather than assumed**: Spearman
ρ = 0.826625 (p = 2.34566e-05) over n = 18 shared drugs, identical to the
published 0.827 / 2.35e-05 / 18.

The reason is that no model is in the loop for this number. `gdsc_hgcc_concordance`
joins two independent wet-lab screens (GDSC median LN_IC50 vs HGCC mean
sensitivity) by normalised drug name and correlates them. It reads
`data.real.drug_response` and nothing from `reconstruct`, `sim` or `physics`.
The `resolve_ic50` measured-library subset is also unchanged
(temozolomide, methotrexate, cisplatin). Immunity confirmed.

## 7. Scope and caveats

* `reconstruction_fidelity` CHECK 3 (deconvolution subsampling stability and
  held-out pseudobulk recovery) was **not** re-run. It exercises only
  `reconstruct.deconvolve` against the Darmanis reference, which none of the
  four changes touched, and it is the slowest check in the module. It is
  untested-after, not verified-unchanged, and is called out rather than assumed.
* `pharmacology_real`'s descriptor-QSAR half (`descriptor_model_vs_baseline`)
  was not re-run; only the concordance claim named in the task was. Same
  reasoning — it has no path into the changed code — but same caveat.
* The regional permutation statistics in (a) use the module's shipped
  20,000-permutation default with `seed = 0`, matching the committed report.
* No `results/*.md` other than this file was written. The five validation
  modules' own reports are untouched, so the "before" side of every row above
  can be re-read from the artefact that made the claim.
