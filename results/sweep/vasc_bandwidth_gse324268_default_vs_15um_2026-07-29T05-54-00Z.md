# Does the vascular-KDE bandwidth finding generalize off the flagship section? — GSE324268 366-gene panel

Second-patient check on `results/vascular_validation.md`'s "vasculature is statistically close to random" finding. Reconstructed the current re-anchored flagship section per `results/flagship_markers.md`: `reconstruct_real("xenium", sample="data_cache/gse324268_xenium", dx_um=12.0, state_mode="markers")` — 851,509 cells (515,887 tumour, 74,515 endothelial), tissue area 98.47 mm². Confirmed default bandwidth: `real_fields._DEFAULT_BANDWIDTH_UM = 40.0` µm (`mode='kde'`; note the pipeline's actual DEFAULT vascular construction is now `mode='discrete'`, which ignores bandwidth entirely — the 40 µm KDE is an explicit, non-default option on both sections). All numbers below built the KDE field in-memory (`vascular_density_from_cells(domain, cells, bandwidth_um=B, mode='kde')`); no existing file touched. Methodology matches the parallel bandwidth-sweep already running on the original 319-gene flagship (`results/sweep/vasc_bandwidth_{08,12,14,16}um_*.md`), reused here for comparability.

**Yes, this second patient/panel shows the same problem, and no, 15 µm does not fix it there either — the effect is section-invariant, and it is invariant for the same structural reason on both sections.** The diagnostic that actually tests "is the vasculature arranged randomly" — the cell-coordinate CSR test — never touches the KDE field at all (it clusters raw endothelial-cell positions via DBSCAN, independent of any bandwidth), so on GSE324268 it reproduces a near-random verdict (0.94×, materially the same conclusion as the flagship's 0.99×) at *every* bandwidth simultaneously, by construction — rebuilding the field at 15 µm cannot move this number because the number was never a function of bandwidth. What *does* move with bandwidth is the smoothed field's own geometry: narrowing 40→15µm collapses the p95-threshold "hotspot" distance by >5× (429.7→80.5µm) purely because a narrower kernel fragments a few large blobs into many small, closely-packed local maxima — not because it recovers real vascular clustering — while the 500µm-tile heterogeneity of the field barely changes (3.49×→3.47×) either way, on both sections. GSE324268's raw endothelial-density heterogeneity (4.65×) is nearly double the flagship's (2.42×), so the two sections are not identical in magnitude — but they agree on the qualitative verdict and on which knob can and cannot touch it. Bottom line for the synthesis pass: bandwidth is not a lever that fixes the random-arrangement finding on either section; a fix requires changing the vessel-clustering/CSR-null construction itself (e.g. `vascular_validation.py`'s DBSCAN linking or object model), not `_DEFAULT_BANDWIDTH_UM`.
