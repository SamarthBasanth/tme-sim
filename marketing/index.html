Platform

Upload tissue. Get a mechanism, not a guess.

Four steps, and every one of them is real computation on real measured data — not a template applied to a diagnosis.

01

Upload

Point it at Xenium or Visium output — or a generic matrix-plus-coordinates layout. The system detects what it’s looking at, checks the gene panel against what a run will need, and reports honestly what it can and cannot support. A missing marker is a stated limitation, not a silent guess.

02

Reconstruct

Vasculature, extracellular matrix, and oxygen are built from that specimen’s own measured markers — not a population average or a generic tumor template. If a panel can’t measure something, the reconstruction says so instead of filling the gap.

03

Simulate

A convection–diffusion–reaction solver moves the drug through the tissue you actually reconstructed. Pharmacokinetics, protein binding, blood–brain-barrier partitioning, and Hill pharmacodynamics run on the same grid — not a compartment model standing in for geometry.

04

Attribute

Every surviving tumor cell gets a reason: never reached, underdosed, resistant, or chance. The attribution reconciles bit-for-bit against the kill fraction it explains — not just plausible, checked.

Why glioblastoma first

The cancer where geometry decides the outcome.

Most solid tumors respond according to intrinsic sensitivity — genetics, receptor status, driver mutations. Glioblastoma is the exception that makes a transport-physics model matter: the blood–brain barrier makes delivery itself the dominant clinical variable, not a footnote to it. It’s why we started here — the model earns its keep exactly where geometry, not just biology, decides whether the drug arrives.

Current scope. Reconstruction runs on a single measured tissue section (2-D). Registering multiple serial sections at known z-spacing into a genuine 3-D microenvironment is in active development — using the same real, measured tissue data, not a synthetic volume.

Rigor

Built to be checked, not trusted.

The output is not just a number. It’s a number with a stated origin, and a system that would rather stop than guess.

P

Provenance on everything

Every value on screen says where it came from — measured, computed from measured, literature, or assumed. A value computed from an assumed input is labeled assumed, never upgraded by proximity to real data.

measured computed literature assumed
R

Refuses rather than defaults

An unsupported gene panel, a missing unit, an unrecognized drug — the system stops and states the reason, instead of quietly filling in a plausible number.

refused — unsupported panel
B

Reconciled, not just reported

Per-cell mechanism attribution is checked bit-for-bit against the kill fraction it explains. Not “this is probably why” — the same arithmetic that produced the result, read back out.

T

Transport physics, not a lookup table

A convection–diffusion–reaction PDE, solved on the tissue’s own measured geometry — grid-convergence checked, not assumed.
